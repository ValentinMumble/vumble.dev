# 🧀 vumble

Homepage of https://vumble.dev. A single static `index.html` that lists my projects.

On each visit it reads my public GitHub repos and shows the ones that are not forks and not archived. A repo with a website set links to it; one without links to its GitHub page. If the GitHub API can't be reached, a built-in copy of the list is shown.

Deployed on Vercel (project `vumble-dev`), on every push to `main`.
