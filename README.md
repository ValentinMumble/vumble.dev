# vumble.dev

Homepage of https://vumble.dev. A single static `index.html` that lists my web projects.

On each visit it reads my public GitHub repos and shows the ones that are not forks, not archived, and have a website set. So adding a homepage URL to a public repo adds it to the page. If the GitHub API can't be reached, a built-in copy of the list is shown.

Deployed on Vercel (project `vumble-dev`), on every push to `main`.
